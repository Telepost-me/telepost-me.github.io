# Пост с текстом и картинкой (картинка под текстом)

При создании выбираем тип поста «Текст»:

![image](/images/b50d2080-5c44-11eb-91ba-056c59621c2f.png)

Нажимаем на кнопку <kbd>Прикрепить фото</kbd>:

![image](/images/e0900b00-5c44-11eb-8eb2-eeaf7600cbc2.png)

После этого пост будет состоять из текста, под которым будет прикрепленное фото. Пример:

![image](/images/1208d680-5c45-11eb-815f-af06a07abf13.png)
